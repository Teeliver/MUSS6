# ADR-001 — Bộ khung web độc lập, 2026-10-23

Trạng thái: chấp nhận cho M01; chưa quyết định renderer gameplay M05.

M00 đã có inventory và các audit tái lập, nhưng còn ngoại lệ/thiếu engine gốc và baseline visual. Các việc thiếu này tiếp tục mở. Có thể dựng build trống và quy ước quản lý song song vì không thay protocol, dữ liệu hoặc asset. Không gọi đây là đóng M00.

M01 dùng ES modules JavaScript trực tiếp, WebGL2 để kiểm tra context, Node 26.11.1 và npm 11.20.0 đã có tại máy. Pin trong package.json và .node-version; build từ chối Node khác phiên bản. Chưa có dependency npm nên chưa tạo lockfile. Khi thêm TypeScript/Three.js hoặc dependency khác phải có ADR cập nhật và lockfile trước khi dùng. ES modules hiện tại không quyết định cách viết renderer cuối cùng.

Build dùng allowlist 4 file tĩnh; không nhập native CMake, Cocoa/Objective-C++, Data gốc, báo cáo local, .env hoặc server config. Output là web/dist bị ignore. Chưa có WASM target hoặc portable core; chúng thuộc M02. Chỉ tạo chỗ giữ gateway, chưa có kết nối mạng/gateway executable.

Trang diagnostics sử dụng font hệ thống để đọc trạng thái kỹ thuật, không phải UI game. Không chọn font thay thế cho font MU. Canvas chỉ clear một màu, vẽ khi resize/context phục hồi, không chạy vòng giả lập FPS hoặc tiến trình tải giả.

Chưa kiểm tra browser/WebGL context thực, shader, GPU, font, Windows parity hoặc 60 FPS. Build/test Node không thay thế các kiểm tra đó.

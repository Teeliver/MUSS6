## Lỗi build phát hiện khi chạy thật

Trang ban đầu đứng trước khởi tạo WASM. Log HTTP cho thấy `src/ui/item-use-policy.js`404, trong khi world-session đang import module này. File source có sẵn nhưng chưa được đưa vào allowlist. Đã đưa vào gói debug; không đổi logic dùng item của module.

Build nay kiểm tra graph module import tương đối/literal bắt đầu từ script entrypoint trong HTML trước khi thay dist. Thiếu module sẽ báo Unpackaged module dependency và giữ bản dist đang có. Kiểm tra phần graph thực sự reachable để không coi thư viện đóng gói nhưng không dùng trong chế độ release là dependency runtime. Chưa kiểm tra import tính đường dẫn động hoặc mọi URL fetch.

Test build mở rộng để mô phỏng thiếu dependency, xác nhận dist cũ còn nguyên, rồi kiểm tra CSS sai như trước. Bản release tối giản vẫn chưa có gameplay đầy đủ; việc test đóng gói qua không thay thế hạng mục phát hành trong kế hoạch.

Kiểm tra cổng trong sandbox bị giới hạn, không được dùng để kết luận server dừng. Đã kiểm tra ngoài sandbox: MySQL/Connect/Join/Data/Game/Identity/Gateway/Web đều đang nghe. Không restart dịch vụ hoặc sửa DB/nhân vật.

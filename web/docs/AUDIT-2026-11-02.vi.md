## Đã sửa trong đợt này

### 1. NPC price list `C1:F3:E7`
- File: `web/client/src/protocol/npc-shop.js`
- Lỗi:
  - Code chỉ nhận packet wide `C2/C4`.
  - Server gửi `PSWMSG_HEAD` C1 với size 2 byte → head nằm ở byte 3, sub ở byte 4.
- Đã sửa:
  - Tự nhận diện `PSWMSG` C1 bằng `(b[1]<<8|b[2])===b.length`.
  - Đọc đúng `F3:E7`, `count`, `type`, entry 20 byte.
- Test: `tests/npc-price-list.test.mjs`.

### 2. Leak listener Command Window
- File: `web/client/src/ui/game-ui.js`
- Đã đổi listener ẩn danh thành named:
  - `commandKey`
  - `commandEscape`
- `dispose()` gỡ:
  - `mu-command-menu`
  - `commandKey`
  - `commandEscape`

### 3. `clear()` không dọn Command Window
- Đã thêm:
  - ẩn `command.outer`
  - `commandSelected=-1`
  - clear `commandPlateTimer`
  - ẩn `commandPlate`
  - reset `friendTab`, `friendChatReject`, `letterScroll`

### 4. Trade timer không hủy khi close
- File: `web/client/src/session/world-session.js`
- `close()` giờ clear + reject:
  - `tradeMoveRequest`
  - `tradeMoneyRequest`

### 5. Decode lỗi làm disconnect
Đã bọc riêng:
- chat packet
- mail result/alert/text/delete
- NPC apply

Packet lỗi giờ chỉ hiện notice và bỏ qua, không đóng session.

### 6. Portrait WebGL context leak
- File: `web/client/src/world/live-view.js`
- Dùng 1 canvas/context WebGL tái sử dụng.
- Render xong copy sang canvas 2D của UI.
- `dispose()` gọi `WEBGL_lose_context`.

- `Main5.2/source/WSclient.cpp`: `ReceiveLetterText`.
- `DataServer/Friend.cpp` + `GameServer/Friend.cpp`: luồng `Dir`/`Act` của mail.

### Giao diện
- Write: cửa sổ 370×216; ảnh 119×167 đặt `left=251`, `top=30` (right-119 theo `SetArrangeType(1,119,30)`); `Send/Close` ở `y=200`; `Prev./Next Action` ở `x=250/301, y=200`.
- Read: cửa sổ 370×182; ảnh 119×167 đặt `left=251`, `top=15`; nút `Reply/Delete/Previous/Next/Close` ở `y=166`.
- Bỏ việc ảnh Read luôn đứng yên: đọc `PhotoDir`/`PhotoAction` server trả về để dựng đúng pose, góc, zoom đã lưu.

### Pose
- 24 pose theo đúng mảng `siPose` của `SetPhotoPose`.
- Map `AT_*` → `PLAYER_*` theo `_enum.h`, có nhánh nam/nữ.
- `AT_STAND1`/`AT_MOVE1`/`AT_ATTACK1` lấy action idle/walk/attack theo vũ khí qua `equipmentActionsResult`.
- Sửa lỗi canvas biến mất: dùng geometry từ `actor.model` (đã có texture) thay vì geometry sample chưa gắn `image`.

### Tương tác
- Kéo chuột trái: 1 px = 1°.
- Lăn chuột: ±0.05, kẹp 0.8–1.1.
- Chuột phải: reset góc/zoom ban đầu.
- `Prev./Next Action`: chuyển pose theo vòng 24 pose.
- Canvas ảnh phải `pointer-events:auto` vì CSS HUD đang đặt `canvas { pointer-events:none }`.

### Packet
- Send: byte 78 = `Data1 = (zoomIndex << 6) | (angle/6 & 0x3F)`; byte 79 = `Data2 = pose - AT_ATTACK1`.
- Read: byte 26 = `PhotoDir`, byte 27 = `PhotoAction`; giải mã góc `(dir & 0x3F) * 6`, zoom `((dir >> 6) * 10 + 80) / 100`.
- Sửa `WZ_WriteMail`: `p_direction/p_action` phải là `TINYINT UNSIGNED` (SQL Server `TINYINT` là 0–255). Trước đây `Act > 127` làm procedure lỗi trong `STRICT_TRANS_TABLES`, server trả result 0.
- Đã apply procedure mới vào MySQL local.
